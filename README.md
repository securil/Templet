# 패션 의류 쇼핑몰 상세페이지 템플릿 (와디즈 스타일)

이 템플릿은 패션 의류 쇼핑몰의 상품 상세 페이지를 위한 재사용 가능한 HTML/CSS/JS 템플릿입니다. 와디즈 스타일의 톤앤매너와 효과를 적용하여 크라우드펀딩 또는 프리오더 형식의 제품 페이지에 적합합니다. 구조와 데이터를 분리하여 유지보수가 용이하도록 설계되었습니다.

## 라이브 데모

GitHub Pages를 통해 라이브 데모를 확인할 수 있습니다:  
[패션 의류 쇼핑몰 템플릿 데모](https://securil.github.io/Templet/)

## 파일 구조

```
├── index.html                   # 메인 HTML 템플릿
├── css/                         # CSS 스타일 폴더
│   └── style.css                # 메인 스타일시트 (와디즈 스타일 적용)
│
├── js/                          # JavaScript 폴더
│   └── product-loader.js        # 구글 시트에서 데이터를 로드하는 스크립트
│
└── images/                      # 이미지 폴더
    └── icons/                   # SVG 아이콘 폴더
        ├── linen-icon.svg       # 린넨 소재 아이콘
        ├── loose-fit-icon.svg   # 루즈핏 아이콘
        └── ...                  # 기타 아이콘들
```

## 주요 기능

1. **구글 시트 연동**: 상품 데이터를 구글 시트에서 관리하고 불러옵니다.
2. **드롭다운 메뉴**: 여러 제품을 드롭다운 메뉴로 쉽게 선택할 수 있습니다.
3. **인쇄 기능**: 현재 표시된 제품 페이지를 인쇄할 수 있습니다.
4. **반응형 디자인**: 다양한 디바이스 화면 크기에 최적화되어 있습니다.
5. **와디즈 스타일 디자인**: 와디즈 스타일의 디자인 요소와 애니메이션이 적용되었습니다.

## 와디즈 스타일 특징

이 템플릿은 다음과 같은 와디즈 스타일 요소를 적용했습니다:

1. **브랜드 컬러**: 와디즈의 테마 컬러인 청록색(#00b2b2)을 활용
2. **스크롤 애니메이션**: 페이지 스크롤 시 요소들이 자연스럽게 등장하는 애니메이션 효과
3. **모던한 카드 디자인**: 정보를 명확하게 전달하는 카드 기반 UI
4. **호버 효과**: 요소에 마우스를 올렸을 때 미묘한 애니메이션 효과
5. **전체화면 배너**: 와디즈 프로젝트 페이지와 유사한 전체화면 배너 스타일
6. **타이포그래피**: Pretendard 폰트를 사용하여 현대적이고 가독성 높은 디자인

## 사용 방법

### 1. 구글 시트로 상품 데이터 관리

이 템플릿은 다음 구글 시트와 연동되어 있습니다:
[구글 시트 링크](https://docs.google.com/spreadsheets/d/1RxvH0-l7xxOZZQTYHbBDp8bfbn8-Gyn_qZucGznluXY/edit)

구글 시트에서 상품 데이터를 추가하거나 수정하면 웹페이지에 자동으로 반영됩니다.

### 2. 제품 선택 및 인쇄

상단 드롭다운 메뉴에서 원하는 제품을 선택하고, 인쇄 버튼을 클릭하여 현재 제품 페이지를 인쇄할 수 있습니다.

### 3. 커스터마이징

`css/style.css` 파일을 수정하여 템플릿의 스타일을 변경할 수 있으며, `index.html` 파일을 수정하여 템플릿의 구조를 변경할 수 있습니다.
